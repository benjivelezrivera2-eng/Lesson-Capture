# Agents

This repo is **Local Lesson Capture Helper**: a Chrome extension plus a local collector that saves authorized lesson audio/video to a folder on disk.

## Start here

1. Project skill: `.cursor/skills/lesson-capture/SKILL.md`
2. Human setup / UI: `README.md`
3. AI tool matrix (what works where): `docs/ai-compatibility.md`

## Rules

- Do not change the Windows human capture path unless an issue explicitly asks.
- Never commit lesson media, cookies, tokens, or login data.
- Prefer direct media URLs; there is no recording fallback.
